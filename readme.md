> This is a shared resource archive, not a coding project. It's a collection of course materials I've gathered across my CS semesters, organized here so other students don't have to hunt for slides, past papers, or lab material the way I did.

---

## 📋 What's in Here

Each course has its own folder. Inside you'll typically find some mix of:

- 📑 **Lecture slides** (`.ppt`/`.pptx`)
- 📝 **Course outlines** (official syllabus documents)
- 🧪 **Lab material** — assignments, lab manuals, sample code
- 📄 **Past papers** — midterm and final exam papers from previous semesters
- 💾 **Code/assignment solutions** — where available
- 🎓 **"By senior" / "senior folder"** — notes and material passed down from students who've already taken the course

## 🧭 How to Use This

1. **Find your course folder** from the index above (or just browse the repo)
2. Inside, look for a **course outline** file first — it tells you exactly what's covered and how it's graded
3. Check the **"by senior" / "senior folder"** — these are usually the most useful for exam prep since they're condensed by someone who already passed the course
4. **Past papers** are your best predictor of what's actually going to be asked — go through these before lecture slides if you're short on time

## ⚠️ A Note on Content

Some folders contain scanned textbook PDFs and solution manuals (e.g., Kenneth Rosen's *Discrete Mathematics*, Anton's *Calculus*) that were shared informally within the class for study purposes. These aren't originally authored material — if you're the rights holder of any document here and want it removed, open an issue and I'll take it down.
